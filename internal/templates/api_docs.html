Authentication

Create an API key on the API page. The full key is shown once at creation.

curl -H "Mirador-Api-Key: mir_abcd1234..." \
  http://localhost:8080/api/v1/accounts

Examples

List all accounts

curl -H "Mirador-Api-Key: $MIRADOR_APIKEY" \
  http://localhost:8080/api/v1/accounts

Create a task

curl -H "Mirador-Api-Key: $MIRADOR_APIKEY" \
  -d '{"account_id":1,"title":"Call client","due_date":"2026-12-01","details":"Follow up"}' \
  http://localhost:8080/api/v1/tasks

Mark a task complete

curl -H "Mirador-Api-Key: $MIRADOR_APIKEY" \
  -d '{"completed":true}' \
  -X PUT http://localhost:8080/api/v1/tasks/1

Add a note to a task

curl -H "Mirador-Api-Key: $MIRADOR_APIKEY" \
  -d '{"note":"Left voicemail"}' \
  http://localhost:8080/api/v1/tasks/1/notes
